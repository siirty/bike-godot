# Requirements

Durable, externally meaningful behavior requirements live here. Implementation mechanisms and
rationale belong in architecture and ADRs; empirical constants remain provisional until validated.

- [Tactical training through race situations](tactical-training.md): TT-01–TT-10 define the core
  trainer behavior, player knowledge, background threat, continuity, outcome plausibility and the
  evidence needed to validate them. Accepted in [ADR 0007](../decisions/0007-tactical-training-core.md).

For work items, start from `.ai/task-template.md` and link the applicable requirement IDs. Do not
present accepted requirements as already implemented features.
