# Contributing

Use an issue or task with explicit scope and acceptance criteria. Open a draft pull request for non-trivial changes.

Before marking a PR ready:

1. Run the configured project CI command.
2. Update tests and documentation.
3. Inspect the complete diff.
4. Complete the PR template with actual verification evidence.
5. Confirm no secret, generated noise, or unrelated cleanup is included.

Marking the PR ready triggers the independent Codex review after CI succeeds. Add `ai-review` only when a later coherent revision is ready for another pass.
